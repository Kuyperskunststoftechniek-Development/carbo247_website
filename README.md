# CARBO247 website

One-page site in Vue 3 + Vite.

```bash
npm install
npm run dev      # development server on http://localhost:5173
npm run build    # production build in dist/
```

- Content (text, icons, colours, label positions): `src/data/slides.js`
- Section layout: `src/components/SlideSection.vue`
- Backgrounds: `src/assets/bg/*.webp` (converted from `Background pics/`)
